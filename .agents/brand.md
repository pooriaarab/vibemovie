# Brand Context

## Identity

VibeMovie turns agent coding events into a structured, cinematic recap.
Its core metaphor is a screening room, not a dashboard.

## Audience

VibeMovie serves developers, maintainers, and creators who want shareable coding stories.
They value local control, clear provenance, and repeatable output.

## Promise

Turn raw session events into an intentional story with a useful offline output.
Keep hosted generation explicit and under user control.

## Voice

- Write with cinematic energy, but keep every claim factual.
- Describe the user's work as a story, not a metric stream.
- Prefer concrete actions, scenes, and outcomes.
- State local and hosted behavior precisely.
- Avoid claims about virality, quality, revenue, or future providers.

## Claims

Current source supports these claims:

- Hyperframes renders a self-contained HTML recap without network access.
- The CLI supports `16:9`, `9:16`, and `1:1` output ratios.
- Documentary, speedrun, and meme templates shape scene timing and transitions.
- The package exposes CLI, library, and MCP interfaces.
- Cinematic rendering is optional and requires its declared tools and credentials.

Treat README roadmap items as plans until source and tests prove they ship.

## Naming

- Write `VibeMovie` in prose.
- Write `vibemovie` for commands, package names, and configuration.
- Write `Hyperframes` for the local HTML engine.
- Write `cinematic` for the CLI engine value.
- Use `Vibe Suite` only when describing the wider product family.
